# 0.3.0a1 发布检查

日期：2026-10-30。Windows / Capture One 16.8.6.3784 / Session。

- 21 项针对性检查通过：已知像素波形、ROI、色彩空间、按需统计、过期结果、矢量图中性／纯色位置及同帧数值。
- 标准 MCP SDK 实机七工具发现、原生 PNG 预览、直方图／矢量图图片块、数值及参考比较通过；目标与曝光参数不变，照片写入为零。
- 本机新增桌面两个快捷方式；开启随项目启动器启动。C1 已运行时调用启动器，C1 PID 不变，分析窗口复用；关闭后可单独打开。首次关闭的 C1 同时冷启动尚未新增实测。
- Python 语法、PowerShell 解析、公开文件凭据／私人路径扫描及文档本地链接检查通过。
- 构建 wheel 并核对 ICC 配置和 OpenRV Web MIT 声明被包含；未宣称本轮完成另一台干净 Windows 全安装。
- ZIP 采用明确清单，只附本项目对应源码哈希的桥接 DLL；不发布照片、预览、Session、运行状态、网络诊断或第三方厂商组件。
- 独立波形源仍为 C1 原生渲染 BGRA8。肤色参考不是检测器，源 ICC 假设、历史未决操作和其他未验证范围不因发布消失，见 SCOPES_VALIDATION.md。

运行方式与桌面 AI 安装提示见 [AI_INSTALL_PROMPT](AI_INSTALL_PROMPT.md)。详细现成工具比较见 [SCOPES_REUSE](SCOPES_REUSE.md)。
