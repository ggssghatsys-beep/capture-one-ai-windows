# 验证范围与限制

Mac 开发分支已在 Apple Silicon / macOS 15.7.4 / C1 16.8.6.25 / Session 的 Image 层验证曝光、白平衡、HDR，以及曲线、色阶、Basic/Advanced、色彩平衡的代表性读写、C1 查看器效果及恢复；集合分页、前后选图、两个候选批量通过。显式授权的 Capture Pilot 已通过相邻不同 RAW 的预览、曝光跨照片候选粘贴与恢复、曝光／曲线固定值重置与粘贴及 MCP JPEG 图片块闭环；每次只临时共享当前 RAW，随后停止共享、移除临时相册并恢复浏览位置。重置固定中性值，白平衡除外；未配置原生桥的旧兼容路线中，色彩编辑器仅覆盖 Basic/Advanced。局部七个调色模块、图层选中／改名／启用／透明度、受限蒙版命令和多层整图预览已接通，主体层代表值实测通过；局部 reset/paste 已实现，代表性实测见 MAC_STATUS；官方羽化／完善、普通栅格反相和自建层删除已完成代表性实测；完整色彩编辑器粘贴已接入。可选 AX 的背景 add/subtract/intersect、子蒙版反复定位／删除和局部 Skin 色相更新／恢复已通过产品实机验证；完整图层复制（可选 AX）已通过简单线性渐变层代表性回读、独立修改、等价预览及删除；未配置桥的旧 AX 路线中，其余 Skin 字段已接入但未逐项写测；原生桥七字段更新已有本轮实测；已有简单线性蒙版来源的加／减／相交已通过公共调用和整图预览；显式鼠标后备的图层排序已通过两层代表性回读与预览，完整参数仅层序变化。显式 Viewer 坐标的空层线性渐变（中点 .5）是实验入口，已确认创建、原生回读及 Pilot 整图效果，但与请求位置近似一致尚未验证；当前返回 partial、requested_result_verified=false、model_verified=false，不能视为日常修图已通过的动作；后续原生桥已接通精确 RAW 线性与径向创建；RAW 预览坐标映射仍不可用。详见 [MAC_STATUS](MAC_STATUS.md)。下表为 Windows 历史实测，不可继承到 Mac。

最新 Mac 增量：启用匹配桥后，同类型简单渐变可直接再编辑；Basic／Advanced／Skin 共用后台原生色彩对象并支持完整中性重置；图层复制／排序、来源／AI 蒙版组合和子项选择／删除不再要求前台。已通过本机代表性保存态回读和实际整图查看，具体模式见 [MAC_STATUS](MAC_STATUS.md) 开头；原 AX／鼠标描述仅适用于未配置桥的兼容路径。

截至 2026-10-29，Windows / Capture One **16.8.6.3784** / 一个 Session，以真实 RAW 的登记候选变体进行读、写、回读和预览。本机结果不表示官方支持或所有照片、版本都通过。

此前开发阶段有两名独立审阅者复核及副本实测；不把历史审阅说成本次发布又做一轮。打包只追加分发文件、安装入口和必要检查，不重跑所有参数组合。发布检查见 [RELEASE_CHECKS](RELEASE_CHECKS.md)。

公开包排除私人照片、会话路径、UUID 和完整操作记录，这里是范围摘要，不是可供外部复算的图像数据集。

## 尚未覆盖

- 其他 C1 版本、Catalog、多实例、跨文档；升级需重新核对内部对象。
- 多照片批量编排；当前可逐张操作，不承诺原子批量编辑。
- 全尺寸导出、完整配方验收、独立 ICC 色彩准确性验收。
- 每种相机 RAW、所有蒙版／参数组合、64 点曲线极值。
- 清晰度、锐化、降噪、镜头／几何和人像精修。
- 每个第三方 AI 客户端逐一验收；协议通用不等于客户端都会正确传图。

内部原生对象不是官方公共 API。读写使用 C1 getter/setter、Undo/通知和内核，不写数据库／侧车文件或进程内存地址。保留的显式 UI 兼容入口不改变默认原生路线。

Mac 内部桥已接入公共工具，运行中加载、整图／灰度 PNG、空层线性／径向创建及共享四种图像分析已通过代表性实机闭环，尚未制作 Mac 安装包。含局部层源变体的克隆存在派发前读取拒绝，尚未修复。详见 [MAC_STATUS](MAC_STATUS.md)。
