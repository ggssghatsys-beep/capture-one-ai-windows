# 0.4.0a1 · Windows + 原生 Mac 开发预览

以同仓库最新 0.3.0a3 为基线合并 Mac 开发工作，保留 Windows 客户端及现有 MCP／CLI。新增 Mac 原生调色、图层／蒙版、RGB 分析与菜单栏入口。下载为双平台源码预览，不是签名的独立 Mac 安装包；旧 Windows Release 保持原样。

## 安装与入口

- 把 `docs/AI_INSTALL_PROMPT.md` 交给桌面 AI。安装 AI 先询问是否创建桌面波形图入口，已明确选择则不重复询问。
- Mac：使用已核对的 arm64 Python 3.11+（3.12 实测）运行 `scripts/install_macos.py`，同意桌面入口后加 `--desktop-scopes`。原生桥按 `docs/INSTALL_MAC.md` 在本机构建／显式启用，系统调试授权由用户完成。
- Windows：现有 `Install.ps1 -WithScopes` 保持兼容，安装波形但不建图标可加 `-NoScopesShortcut`；仅装 API 窗口不再创建缺少波形依赖的入口。源码启动器可本机编译本项目 C# 桥，本包不含 Mac 本机 dylib 或厂商组件。
- Mac 关窗隐藏并停读，菜单栏图标保留；桌面重复打开找回同一窗口。退出等当前读取结束，不结束 C1 或共享 owner；无开机自启。

## 本轮效率与稳定性

- 波形窗口优先直接读取 C1 当前完整裁切的原生 RGB 缓冲，不经照片 PNG 编解码；窗口快速样本与 AI exact 分开。持续切图代表值约 0.14～0.16s，首次连接不计入该指标。
- RGB 统计复用已有加权直方图，减少重复扫描；不改变亮度、分位数或蒙版覆盖口径。隔离整函数测量改善约 10～33ms，不冒充宿主端到端性能。
- 修复旧排队请求跨暂停／设置代次执行、通道短暂占用导致长退避、在途读取时退出线程的问题。Windows 兼容导出导航补齐原始观察证据，保持完整回读和不重放保护。

## 已验证与边界

- Mac 代表性宿主环境：Apple Silicon / macOS 15.7.4 / Capture One 16.8.6.25 / Session。原生数值、曲线／色阶、Basic／Advanced／Skin、线性／径向渐变再编辑、主体／背景与受限组合、图层复制／排序、RGB／灰度预览及四图分析的准确范围见 `docs/MAC_STATUS.md`。
- 本轮相关核心／预览检查 115 passed、1 项平台跳过；窗口／桥／分析检查 49 passed。独立源码目录环境安装通过；标准 MCP 七工具发现、原生 PNG、同帧数值／图片／参考检查通过，目标和曝光未变、照片写入为零。AU 复审未发现剩余明确 P1/P2。
- **全套历史测试未全部通过。** 当前全套为 389 passed、116 failed、40 errors、45 skipped（另有 102 子测试通过）；同一环境的原样上游也有旧测试导入错误。排除上游三份不能导入的旧测试后，当前失败／错误测试标识均已存在于该上游对照；这不是全部功能已回归通过的证明。保留有效兼容保护，只移除确已退役的自动恢复／重启测试，不为过测恢复旧功能或降低保护。
- 没有 Windows 实机重测；其他 C1 构建、Intel、Catalog 与真实云端模型/API 未验证。精确局部分析代表值约 0.88s；复杂复合父蒙版整体反选、任意嵌套组合、预览坐标映射和含局部层源照片克隆尚未完成。
- 快速 Viewer 样本保留当前校样效果，均为 8 位预览，不是 RAW 传感器数据。桥为版本绑定的内部接口，不是官方稳定 SDK。

包内清单和 SHA256SUMS 对应本次生成的源码包。排除照片、Session、预览、私人路径、密钥、运行状态和厂商二进制；安装与发布检查不派发照片写入。
